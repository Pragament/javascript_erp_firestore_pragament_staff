System Overview

Welcome to the School Admin System! As a Principal, you have complete control over:

  • Teacher Assignments: Assign teachers to sections with specific roles
  • Section Management: Control who can view or edit each class section
  • Timetable Management: Upload, view, and manage school timetables
  • Academic Year Planning: Copy timetables between years for easy planning
Pro Tip: Always select a School and Academic Year from the dropdowns in the top navigation bar before performing any operations.

Getting Started

Step-by-Step Login Process
1
Open the Application

Navigate to the application URL in your browser.

2
Sign In with Google

Click the "Sign in with Google" button and select your school email account.

3
Select Your School

Use the "Select School" dropdown in the top navigation bar.

4
Select Academic Year

Choose the current academic year from the "Select Year" dropdown.

Important: If you don't see your school in the dropdown, contact the system administrator to add your school to the database.

Managing Teacher Assignments

As Principal, you can assign teachers to sections and control their permissions. Here's how:

Assigning a Teacher
  1. Go to the main dashboard (index page)
  2. Ensure your school is selected in the navbar
  3. In the "Assign Teacher to Section" panel:
    • Select a Section (e.g., "1-A", "2-B")
    • Enter the teacher's email address
    • Select the appropriate Role (see Roles section below)
  4. Click "Assign Teacher"
Editing Assignments
  1. Find the assignment in the assignments table
  2. Click the pencil icon (edit button)
  3. Modify the email or role in the popup
  4. Click "Save Changes"
Tip: The assignments table shows only sections where you have Admin role. Use the filter dropdowns above the table to find specific assignments quickly.
Filtering and Sorting
  • Sort: Click on column headers (Teacher, Section, Role, etc.) to sort
  • Filter: Use the dropdown filters to filter by Section, Teacher, Role, or Assigned By
  • Clear Filters: Click "Clear Filters" to reset all filters

Managing Timetables

Uploading a New Timetable
  1. Click the "Timetable" button in the navbar
  2. Select your School and Academic Year
  3. Go to the "Upload Timetable" tab
  4. Choose upload method:
    • Excel: Drag and drop or click to select Excel file
    • CSV: Select CSV option and upload your file
  5. If CSV, set period times in the modal that appears
  6. When prompted, confirm the Academic Year
  7. Click "Push" to save to Firestore (cloud)
File Format: Excel files should have sheets named as class-sections (e.g., "1-A", "2-B"). CSV files should have headers: Class-Section, Day, P1, P2, P3, etc.
Copying Timetable to Next Year

This feature saves time by copying an existing timetable as a template:

  1. Select your School in the navbar
  2. Click the "Copy Year" button
  3. In the modal:
    • Source Year: The year to copy from (e.g., 2024-25)
    • Target Year: The year to copy to (e.g., 2025-26)
  4. Click "Copy Timetable"
  5. The system automatically switches to the new year
Best Practice: Use Copy Year at the end of each academic year to create the next year's timetable template. Then make minor adjustments rather than starting from scratch.
Viewing and Checking Timetables
  • Class View: See all periods for a specific class
  • Teacher View: See a teacher's weekly schedule
  • Subject View: See when a subject is taught across classes
  • Overlap Check: Detect scheduling conflicts (same teacher assigned to two classes at once)
Managing Holidays
  1. Go to the "Holidays" tab in Timetable
  2. Click "Add Holiday"
  3. Fill in holiday name, date, type, and description
  4. Click "Save Holiday"
  5. Use "Export Holidays" to download as CSV for records

Understanding User Roles

When assigning teachers to sections, you can assign three different roles:

Role Badge Permissions Best For
Admin Admin
  • Full control over the section
  • Assign other teachers to this section
  • Edit timetables
  • View all data
 Class Teachers, Subject Coordinators
Editor Editor
  • Modify timetables
  • View all section data
  • Cannot assign other teachers
 Subject Teachers who need to update schedules
Viewer Viewer
  • View timetables only
  • Cannot make changes
 Substitute teachers, Support staff
Security Note: Only assign Admin role to trusted staff. Admins can assign other users and have full control over their assigned sections.

Best Practices for Principals

Regular Data Backup

Always click "Push" after making important changes to ensure data is saved to the cloud (Firestore).

Use Copy Year Feature

At the end of each academic year, copy the current timetable to the next year as a starting template.

Check Overlaps Regularly

After any timetable changes, run the "Check Overlaps" feature to ensure no teacher scheduling conflicts.

Assign Roles Carefully

Limit Admin roles to class teachers and coordinators. Use Editor for regular teachers who need to update schedules.

Keep Holidays Updated

Add holidays at the start of each academic year. Export the list for school records.

Verify Before Push

Always verify the timetable looks correct (use View Timetable) before pushing to Firestore.

Troubleshooting

Contact the system administrator to add your school to the Firestore database. You'll need to provide:
  • School Name
  • School ID
  • List of sections (classes)

Check the following:
  1. Ensure you are signed in
  2. Verify School and Academic Year are selected
  3. Check internet connection
  4. Open browser console (F12) to check for error messages

Common issues:
  • File format doesn't match expected structure
  • Excel sheets not named correctly (should be "1-A", "2-B" format)
  • CSV missing required columns (Class-Section, Day, P1, P2...)
  • File is corrupted or too large
Try downloading the template file from the Upload Timetable page.

You can only assign teachers to sections where you have Admin role. If a section doesn't appear in your dropdown, it means:
  • You are not assigned as Admin to that section
  • The section hasn't been created in Firestore
Contact the system administrator if you need Admin access to additional sections.
